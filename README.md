# 📌 Overview

The Attendance Management System is a full-stack web application developed to simplify attendance management in educational institutions.

The system supports three user roles:

- 👨‍💼 Admin
- 👨‍🏫 Teacher
- 🎓 Student

Each role has its own secure dashboard with dedicated features.

# 🚀 Installation Guide

### 1 Clone Repository

```bash
git clone https://github.com/vijaylokeshvl/attendance-devops-project
```

### 2 Move Project

Copy the project folder to:

```
xampp/htdocs/
```

---

### 3 Start XAMPP

Start

- Apache
- MySQL

---

### 4 Create Database

Open

```
http://localhost/phpmyadmin
```

Create a database named

```
attendance_management_system
```

---

### 5 Import Database

Import

```
database/attendance_management_system.sql
```

---

### 6 Run Project

Open

```
http://localhost/Attendance-Management-System/
```
